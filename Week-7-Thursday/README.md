# Devops_Week-7

## Student Management Dashboard

A modern, responsive College Student Management Dashboard built with React.js and Vite for managing student profiles, subjects, attendance tracking, and examination details.

### Features
- 🎓 **Header Component**: Displays college name ("ABC Institute of Technology") and portal title.
- 👤 **Student Profile**: Shows student details (Name, Roll Number, Branch, Year).
- 📊 **Attendance Tracker**: Visual progress bar with conditional status badge (**Eligible** $\ge 75\%$ vs **Not Eligible** $< 75\%$).
- 📚 **Subject List**: Dynamic mapping of enrolled courses, faculty, and credit points using `Array.prototype.map()`.
- 📝 **Examination Details**: Card with semester info, hall ticket availability, and results status.
- 🎴 **Student Selector Cards**: Interactive cards to switch active student profiles dynamically.

### Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
