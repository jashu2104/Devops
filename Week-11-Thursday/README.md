## Quick Navigation & Execution

This directory contains the complete implementation for **Assignment 11.1.1** inside [`student-management/`](file:///Users/jashu/Documents/Devops/Week-11-Thursday/student-management/), with top-level convenience symlinks for `backend/`, `frontend/`, and `tests/`.

### Run Backend Unit Tests
```bash
cd backend
npm run test:unit
```

### Run Backend Integration Tests (with PostgreSQL)
```bash
cd backend
npm run test:integration
```

### Run Backend Coverage
```bash
cd backend
npm run test:coverage
```

### Run Frontend Unit Tests
```bash
cd frontend
npm test
```

### Build Frontend Production Bundle
```bash
cd frontend
npm run build
```

### Run Backend Server
```bash
cd backend
npm start
```

### Run Frontend Development Server
```bash
cd frontend
npm run dev
```
